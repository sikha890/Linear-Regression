# Task-3 Linear Regression

## Objective

The objective of this task is to implement and understand Simple and Multiple Linear Regression using Python and Scikit-learn.

## Dataset

Housing dataset containing information about house prices and different house features.

The target variable is `price`.

## Tools Used

- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-learn
- Jupyter Notebook

## Steps Performed

1. Imported the required Python libraries.
2. Loaded the Housing dataset.
3. Inspected the dataset structure and statistics.
4. Checked for missing values.
5. Converted categorical variables into numerical variables using one-hot encoding.
6. Selected features and target variable.
7. Split the dataset into training and testing sets.
8. Implemented Multiple Linear Regression.
9. Generated predictions.
10. Evaluated the model using MAE, MSE, and R² Score.
11. Implemented Simple Linear Regression using area as the predictor.
12. Plotted the regression line.
13. Interpreted model coefficients and intercept.
14. Compared Simple and Multiple Linear Regression.
15. Added interview questions and answers.

## Evaluation Metrics

### MAE

Mean Absolute Error measures the average absolute difference between actual and predicted values.

### MSE

Mean Squared Error measures the average squared difference between actual and predicted values and gives more penalty to larger errors.

### R² Score

R² measures the proportion of variation in the target variable explained by the regression model.

## Conclusion

This task provided practical understanding of Simple and Multiple Linear Regression, data preprocessing, train-test splitting, model training, predictions, evaluation metrics, regression visualization, and coefficient interpretation.
